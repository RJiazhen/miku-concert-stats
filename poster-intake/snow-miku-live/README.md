# snow-miku-live

Catalog series 204, SNOW MIKU LIVE!. The festival site https://snowmiku.com/ is the official domain already recognized by this catalog; this folder is named after the existing concert series, not a newly invented tour. No 演出 from this series is on the setlist-update carousel yet.

When a SNOW MIKU LIVE! programme is added or revised in this catalog, drop the official poster as `{tourId}.jpg` (or `.png` / `.webp`) here and follow the root README to wire `public/posters/` and `data/tour-posters.json`. Recommended delivery: WebP at most 1800px wide via `pnpm posters:compress` (see root README). Prefer 3:4 or similar portrait source; keep the important subject in the upper two-thirds.
