# hatsune-miku-x-kodo

Catalog series 255, 初音ミク×鼓童. This is the existing VocaDB series for the collaboration concerts, including the 2026 響演 edition (performance 12940, tour `hatsune-miku-x-kodo-2026`). This folder is not a newly invented tour.

Current placeholder, already wired in `data/tour-posters.json` and `public/posters/hatsune-miku-x-kodo-2026.webp`:

- Source file: https://kyouen-kodo-miku.com/img/main-visual.jpg
- Official page: https://kyouen-kodo-miku.com/
- Artist credit: ゼンマイブック
- Accessed: 2026-11-23

Drop a corrected poster as `hatsune-miku-x-kodo-2026.webp` (or `.png` / `.webp`) here, then run `pnpm posters:compress --out public/posters` and update the mapping. Recommended delivery: WebP at most 1800px wide via `pnpm posters:compress` (see root README). Prefer 3:4 or similar portrait source; the banner crops the top of the frame into a wide hero with a readability mask.
